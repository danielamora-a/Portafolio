# Portafolio de Gestión y Visualización de Datos

Portafolio de Daniela Mora para Gestión y Visualización de Datos.

**Página web del portafolio:** https://danielamora-a.github.io/Portafolio/

## Organización

Este repositorio contiene el código de la página web. Cada caso está en su propio repositorio de GitHub, con el informe, el archivo de Power BI y los archivos de apoyo. Desde la página web se accede a cada proyecto y, desde la página de cada proyecto, a su repositorio.

| Proyecto | Página en el portafolio | Repositorio |
|---|---|---|
| Caso 1: ¿Vender más siempre significa ganar más? | [proyecto1.html](https://danielamora-a.github.io/Portafolio/proyecto1.html) | [Caso1_PowerBI](https://github.com/danielamora-a/Caso1_PowerBI) |
| Caso 2: ¿Dónde hay un desajuste entre inventario y ventas? | [proyecto2.html](https://danielamora-a.github.io/Portafolio/proyecto2.html) | [Caso2_DM](https://github.com/danielamora-a/Caso2_DM) |
| Caso 3: Las ventas crecen 20 %, pero el margen cede | [proyecto3.html](https://danielamora-a.github.io/Portafolio/proyecto3.html) | [Caso3_DM](https://github.com/danielamora-a/Caso3_DM) |

## Contenido de este repositorio

| Archivo o carpeta | Descripción |
|---|---|
| `index.html` | Página principal: Sobre mí, Herramientas y Proyectos |
| `proyecto1.html`, `proyecto2.html`, `proyecto3.html` | Páginas de cada proyecto |
| `images/` | Capturas de los dashboards, diagramas y visuales |
| `assets/` | Estilos y scripts de la plantilla |

Diseño basado en la plantilla Stellar de [HTML5 UP](https://html5up.net)
